Deck-API

Laat een AI-assistent of script presentaties publiceren, zonder browser. Je maakt hieronder een API-sleutel; de tool stuurt de markdown op en krijgt een vaste link terug. Het formaat van de markdown staat in de deck-readme.

Instellen

Zet de sleutel en het adres in je omgeving, niet in een script of prompt:

export W4_BRANDBOOK_URL=https://brandbook.example
export W4_BRANDBOOK_KEY=w4_…

Een sleutel mag precies wat jij mag: presentaties maken, vervangen en verwijderen. Sleutels beheren kan alleen hier in de browser. Kwijt of gelekt? Trek hem hierboven in.

Publiceren

Stuur de markdown als JSON. visibility is private (standaard, alleen na inloggen te zien) of public (iedereen met de link). jq zet een bestand veilig om naar een JSON-string: 

jq -n --rawfile md deck.md '{markdown: $md, visibility: "private"}' \
  | curl -sS -X POST "$W4_BRANDBOOK_URL/api/presentations" \
      -H "Authorization: Bearer $W4_BRANDBOOK_KEY" \
      -H "Content-Type: application/json" \
      --data @-

Antwoord (201):

{
  "id": "k7m2q",
  "title": "Kwartaalupdate",
  "visibility": "private",
  "url": "https://brandbook.example/present/k7m2q",
  …
}

Optioneel: title (anders leeg; de deck-tool vult hem uit de title: in de front matter) en options met footerText en transition (slide, fade, convex, none).

Vervangen, ophalen, verwijderen

Vervangen houdt de link gelijk. Stuur alleen wat verandert:

jq -n --rawfile md deck.md '{markdown: $md}' \
  | curl -sS -X PUT "$W4_BRANDBOOK_URL/api/presentations/k7m2q" \
      -H "Authorization: Bearer $W4_BRANDBOOK_KEY" \
      -H "Content-Type: application/json" --data @-

# zichtbaarheid wisselen
curl -sS -X PUT "$W4_BRANDBOOK_URL/api/presentations/k7m2q" \
  -H "Authorization: Bearer $W4_BRANDBOOK_KEY" \
  -H "Content-Type: application/json" -d '{"visibility":"public"}'

# lijst, één ophalen (met markdown), verwijderen
curl -sS "$W4_BRANDBOOK_URL/api/presentations" -H "Authorization: Bearer $W4_BRANDBOOK_KEY"
curl -sS "$W4_BRANDBOOK_URL/api/presentations/k7m2q" -H "Authorization: Bearer $W4_BRANDBOOK_KEY"
curl -sS -X DELETE "$W4_BRANDBOOK_URL/api/presentations/k7m2q" -H "Authorization: Bearer $W4_BRANDBOOK_KEY"

Statuscodes

  • 201 aangemaakt, 200 gelukt, 204 verwijderd.
  • 400 ongeldige invoer; de reden staat in error.
  • 401 geen of een ingetrokken sleutel.
  • 404 bestaat niet, of je mag hem niet zien. Die twee onderscheiden we bewust niet, zodat niemand kan raden welke privé links bestaan.

Permalinks

Een link is /present/ plus vijf tekens: kleine letters en cijfers, zonder 0, 1, o, i en l, zodat je hem ook kunt voorlezen. Hoofdletters worden kleine letters.
