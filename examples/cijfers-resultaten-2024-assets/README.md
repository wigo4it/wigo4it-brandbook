# Bronassets

De meeste afbeeldingen komen uit `examples/Wigo4it Numbers&Results 2024.pptx`.

De grote cloud is als groep geëxporteerd vanuit PowerPoint. De oorspronkelijke Socrates-PNG is bewaard als bronreferentie. Slide 6 gebruikt het SVG-beeldmerk uit `img/logo`, in donkergroen via een SVG-masker.
De oorspronkelijke PNG-kaart is bewaard als bronreferentie. Slide 3 gebruikt nu
`nederland-g4.svg`, een vectorkaart op basis van Wikimedia. Zie
[de bronvermelding en licentie](nederland-bronvermelding.md).
Het icoon op slide 2, de kleine cloud, de blauwe landmassa en de vijf partnerlogo’s zijn rechtstreeks uit
het PPTX-bestand gehaald. De partnerlogo’s blijven SVG.

De overige iconen, vormen en het Wigo4it-logo verwijzen naar de bestaande `img/`-assets.
