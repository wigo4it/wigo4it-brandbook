# Assets

Alles wat in `img/` van het brandbook staat. Gebruik uitsluitend deze namen; een naam die er niet
in staat levert een lege plek op de slide op. De machineleesbare versie staat in `assets.json`
naast dit bestand, het origineel op
https://wigo4it-brandbook.azurewebsites.net/assets.json

Overzichtspagina's met plaatjes erbij:
[iconen](https://wigo4it-brandbook.azurewebsites.net/icons.html) ·
[vormen](https://wigo4it-brandbook.azurewebsites.net/shapes.html) ·
[foto's](https://wigo4it-brandbook.azurewebsites.net/photos.html) ·
[logo's](https://wigo4it-brandbook.azurewebsites.net/logos.html)

## Iconen

Gebruik als `icon:Naam`. Namen met een spatie tussen dubbele quotes: `icon:"Game Boy"`.

Aarde · Alarm · Auto · Bier · Bliksem · Bom · Boot · Diamant · Drop · Duckie · Eek · Elixir ·
"Fiets Px" · Formidabel · "Game Boy" · "Game Over" · Hart · Hi5 · Ijsje · Invasion · Kaars ·
Koffie · Laptop · Pacman · Paraplu · Pilon · Pin · Potlood · Prullenbak · Regen · Rex · "Rex 2" ·
Rocket · "Snelle auto" · Vuur · Zandloper · Zon · Zwaard

Een paar die vaak van pas komen:

| Onderwerp | Icoon |
| --- | --- |
| Start, lancering, ambitie | Rocket |
| Overleg, informeel, pauze | Koffie |
| Techniek, werkplek | Laptop |
| Snelheid | Bliksem, "Snelle auto" |
| Risico, incident | Bom, Alarm |
| Tijd, doorlooptijd | Zandloper |
| Waarde, kwaliteit | Diamant |
| Samenwerking | Hi5, Hart |
| Idee, ontwerp | Potlood |
| Opruimen, schrappen | Prullenbak |

## Vormen

Gebruik als `shape:naam@positie`. Posities: `topleft`, `topright`, `bottomleft`, `bottomright`.
Bijvoorbeeld `shape:quarter-ring-bottom-left@bottomleft`.

arch-open-bottom · circle · diamond · pill-extra-wide · pill-medium · pill-narrow · pill-wide ·
quarter-circle-bottom-right · quarter-ring-bottom-left · quarter-ring-bottom-right ·
quarter-ring-top-left · quarter-ring-top-right · rectangle-round-right-narrow ·
rectangle-round-right-wide · rectangle-tall · ring · semicircle-right · square ·
triangle-diagonal · triangle-right

Kies een vorm die bij zijn hoek past. Een `quarter-ring-bottom-left` hoort linksonder, een
`quarter-ring-top-right` rechtsboven. Een `ring` of `circle` kan overal.

## Foto's

Alleen bij de `photo`-layout, als markdown-afbeelding met het pad erbij:
`![](img/photos/team-meeting.jpg)`

| Bestand | Wat je ziet |
| --- | --- |
| `img/photos/colleages-discussing.jpg` | collega's in gesprek |
| `img/photos/group-looking-at-laptop.jpg` | groepje kijkt mee op een laptop |
| `img/photos/man-working-on-laptop.jpg` | man werkt op een laptop |
| `img/photos/man-writing-code.jpg` | man schrijft code |
| `img/photos/team-meeting.jpg` | teamoverleg |
| `img/photos/woman-sticking-note-to-wall.jpg` | vrouw plakt een briefje op de muur |

Let op de spelling van `colleages-discussing.jpg`. Die typefout zit in de bestandsnaam en moet je
overnemen.

## Logo's

Zet zelf geen logo in een deck of document: de tools doen dat. Deze lijst is er voor ander gebruik,
zoals een Teams-achtergrond of een sjabloon.

| Bestand | Waarvoor |
| --- | --- |
| `img/logo/Logo.svg` | het volledige logo op een lichte achtergrond |
| `img/logo/Logo Diap.svg` | diapositief, voor donkere achtergronden |
| `img/logo/4.svg` | alleen het beeldmerk |
| `img/logo/4 Diap.svg` | beeldmerk diapositief |
| `img/logo/logo darkmode pill.png` | logo in een pill, voor donkere modus |
| `img/logo/W4_logo_M365.png` | voor Microsoft 365 |
| `img/logo/W4_logo_M365_Darkmode.png` | voor Microsoft 365, donkere modus |

Alle assets zijn ook per stuk te downloaden via de overzichtspagina's, of via de URL
`https://wigo4it-brandbook.azurewebsites.net/` plus het pad hierboven.
